\section{Introduction and Implementation}
This project explores the application of Deep Reinforcement Learning using the \textbf{Proximal Policy Optimization (PPO)} algorithm within the \textit{Gym MiniGrid} framework. The core objective was to develop an agent capable of navigating complex, logic-driven environments through custom reward engineering and optimized neural architectures.

\subsection{Task Definition and Environment Components}
\begin{itemize}
    \item \textbf{Navigation Logic:} The agent must solve multi-stage puzzles requiring inventory management (key collection) and environment manipulation (unlocking doors). Three custom map classes (\texttt{First}, \texttt{Second}, and \texttt{Third}) were developed for this purpose.

    \item \textbf{Custom Entities:} To enhance environmental complexity, the \newline \texttt{RimWorldEnemy} class was implemented.

    \item \textbf{Observation Space:} Observations consist of a partially observable $11\times11$ grid. This spatial data is processed as an image-like tensor, allowing the agent to perceive both static terrain and dynamic threats.
\end{itemize}

\subsection{Architectural Refinements and Evaluation}
\begin{itemize}
    \item \textbf{Feature Extraction:} A custom \textbf{Convolutional Neural Network (CNN)} serves as the feature extractor. A lightweight visual encoder was implemented, consisting of three consecutive 2D convolutional layers (using $2 \times 2$ kernels). These layers progressively expand the feature channels ($16 \rightarrow 32 \rightarrow 64$) before applying a ReLU activation and projecting the spatial state into a 128-dimensional vector through a linear layer.

    \item \textbf{Learning Dynamics:} The \textbf{Proximal Policy Optimization (PPO)} algorithm was selected for its robust clipping mechanism, which prevents catastrophic policy updates during the critical phases of reward discovery. The custom CNN was integrated into PPO's \texttt{CnnPolicy} actor-critic framework. The network weights were optimized using a learning rate of $3 \times 10^{-4}$.

    \item \textbf{Visual Evolution Monitoring:} To assess the agent's progress, \newline \texttt{video\_overlay.py} and \texttt{plot\_run\_data.py} utility was developed. \newline \texttt{video\_overlay.py} utilizes \textbf{OpenCV} to produce blended video comparisons (\texttt{.mp4}) between a baseline random agent and the trained PPO agents, and \texttt{plot\_run\_data.py} visualizes information regarding the \textit{Average Return} and \textit{Episode Length}

    \item \textbf{Performance Evaluation:} The \texttt{evaluate\_agents.py} script runs the trained agents through multiple deterministic episodes to calculate key performance metrics, namely the overall \textit{Success Rate} and \textit{Average Return}. This provides a robust statistical validation of the agent's capabilities across the different environment complexities.
\end{itemize}

\section{Environment Layouts and Map Design}
To evaluate the agent's performance across different levels of complexity, three distinct environment classes were developed. Each map introduces unique spatial constraints and logic requirements.

\subsection{Map 1: Hazard Avoidance}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.45\textwidth]{images/first.png}
    \caption{\textbf{First Map:} A dual-room configuration featuring a locked door mechanism, lava hazards, and dynamic enemies.}
    \label{fig:map1}
\end{figure}
The \textit{First} map (see Figure \ref{fig:map1}) consists of a two-room layout separated by a locked door. The agent must navigate a simple corridor, avoid lava pits and Enemy entities to reach the goal (indicated by the green square). To address size of the $16×16$ state space, a dense reward shaping strategy was implemented, utilizing multi-stage sub-goals to effectively guide the agent's policy convergence.

\subsection{Map 2: Sequential Logic and Inventory Management}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.45\textwidth]{images/second_v2.png}
    \caption{\textbf{Second Map:} A multi-stage logic environment requiring key exchange and non-linear pathfinding.}
    \label{fig:map2}
\end{figure}
The \textit{Second} map (Figure \ref{fig:map2}) introduces a different design. It requires multi-stage logic where the agent must pick up a blue key, open the corresponding door, and subsequently drop the first key in order to handle a second key/door sequence before finding the goal. Unlike the \textit{First} map, we follow a sparse reward shaping strategy, given the size of the $8x8$ state space.

\subsection{Map 3: Exploration and Spatial Generalization}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.45\textwidth]{images/third_v2.png}
    \caption{\textbf{Third Map:} A dense navigation Maze focused on finding the Shortest Path.}
    \label{fig:map3}
\end{figure}
The final \textit{Third} environment (Figure \ref{fig:map3}) is a dense maze focused on pure navigation efficiency. The maze consists of several dead ends but lacks the enemies and inventory management the other two maps required. Similarly to the \textit{Second} Map, we again follow a sparse reward shaping strategy.

\subsection{Custom Entity Rendering}
An extension to the environment's visual capabilities is the implementation of the \texttt{RimWorldEnemy} class. The render of the enemy was inspired by the style of games like \textit{RimWorld} and \textit{Prison Architect} to add some flavor.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.2\textwidth]{images/enemy_render.png}
    \caption{\textbf{Custom Enemy Sprite}}
    \label{fig:enemy}
\end{figure}

The rendering process (see \texttt{enemy.py}) utilizes \textbf{fill\_coords} to layer the body, clothing, and facial features in a specific Z-order, and a helper utility (\textbf{point\_in\_ellipse.py}) to define the boundaries for the color filling.

Similarly to the \texttt{Lava} object in \textit{MiniGrid}, any overlap with the \texttt{RimWorldEnemy} class triggers an immediate episode termination and a significant reward penalty.

This addition introduces a higher level of visual and logical complexity; the \textbf{CNN} model is forced to distinguish between different "lethal" entities (e.g., orange static lava vs. red dynamic enemies), preventing the agent from relying on simple color-blob heuristics.

\section{Reward Engineering}

\subsection{Map 1: Dense Reward Shaping}
To accelerate convergence, the task was decomposed into a \textbf{Finite State Machine} with sub-goals:
\begin{itemize}
    \item \textbf{Navigation Guidance:} Implemented a "Compass" system using \textit{Manhattan Distance} to provide immediate mathematical feedback during the initial training phases.
    \item \textbf{Sub-goal Rewards:} Assigned discrete bonuses for critical actions (map-specific), $+0.5$ for key pickup, $+1.0$ for opening the locked door; small per-step shaping for moving closer to the current phase target ($+0.1$ when distance decreases in Phases 1--2, and $+0.05$ when approaching the goal in Phase 3).
    \item \textbf{Time Penalty:} A constant step penalty of $-0.005$ is applied to incentivize shorter solutions.
    \item \textbf{Failure Penalties:} Collisions with lethal tiles or enemies incur on larger negative rewards and typically terminate the episode.
\end{itemize}

\subsection{Map 2: Sequential Logic and Event-Driven Rewards}The reward sructure for the puzzle relies strictly on discrete phase progression and inventory management:
\begin{itemize}
    \item \textbf{Event-Based Sub-goals:}  Assigned discrete bonuses for critical actions (map-specific), $+0.5$ for key pickup, $+1.0$ for opening the locked door, same as \textit{Map 1};
    \item \textbf{Inventory Penalty:} To enforce item retention, a strict penalty of -2.0 is applied if the agent drops a required key, which also triggers immediate episode termination.
\end{itemize}

\subsection{Map 3: Pure Sparse Rewards}
In this environment, heuristic guidance and sub-goals are completely eliminated to evaluate the agent's spatial generalization and exploratory capabilities:
\begin{itemize}
    \item \textbf{Terminal Reward:} The agent receives positive reinforcement solely upon successfully completing the entire mission and reaching the final goal.
    \item \textbf{Time Penalty:} A constant step penalty of -0.05 serves as the only environmental feedback during navigation. This strict sparsity forces the algorithm to rely entirely on intrinsic exploration (entropy) to discover the terminal state without any intermediate breadcrumbs.
\end{itemize}
\section{Results and Evaluation}
To assess the convergence the trained PPO agents, the codebase utilizes \textit{TensorBoard} logging for real-time monitoring of \texttt{ep\_rew\_mean} and \texttt{ep\_len\_mean} (stored under \texttt{app/data/runs/}). Post-training evaluation was conducted using a stochastic methodology: each model was executed for 500 independent episodes with a strictly enforced truncation limit of 200 steps (\texttt{max\_steps=200}).

To contextualize the \textit{Average Return},
a Theoretical Maximum Return was calculated for each map,
accounting for custom event rewards, distance shaping heuristics,
the step-based time penalty ($-0.005$), and the native MiniGrid completion bonus.
The empirical results across 100k, 300k, and 500k timesteps are summarized in Table \ref{tab:results}.

\subsection{Map 1: Dense Reward Convergence}
The theoretical maximum return for Map 1 is approximately $10.35$.
The evaluation highlights rapid convergence due to the dense reward shaping.
The model trained for 300k timesteps achieved a flawless $100\%$ success rate
with an average return of $10.132$. This indicates near-perfect optimal pathing.
The slight variance observed at 100k and 500k timesteps is attributed to
stochastic exploratory noise.

Furthermore, after visual inspection of Figure \ref{fig:map1_metrics}
we notice that at approximately 125k timesteps, the 500k agent experienced
a severe policy collapse (catastrophic forgetting),
with the return plummeting from near-optimal levels to negative values.
However, unlike the permanent degradation observed in purely sparse environments,
the agent successfully recovered its optimal policy by timestep 250k.
The distance-based rewards provided the necessary gradient signals
to guide the model out of the collapsed state and stabilize its navigation strategy.

\subsection{Map 2: Sequential Logic and Local Minima}
Map 2, demonstrated the non-linear progression of deep reinforcement learning.
The theoretical maximum for this environment is $8.816$.
The 100k and 300k models completely failed to reach the terminal state ($0\%$ success rate),
acquiring only the initial key before becoming trapped in a local minimum and timing out.
Extended training allowed the 500k model to escape this local minimum,
successfully executing the full sequence to achieve an $86.8\%$ success rate
and an average return of $7.343$.

\subsection{Map 3: Spatial Exploitation and Catastrophic Forgetting}
The evaluation of Map 3 yielded interesting insights regarding agent behavior.
The theoretical maximum return for navigating the intended labyrinth was calculated at approximately $5.962$.
The 300k agent achieved $100\%$ success rate and an average return of $5.925$ over 500 episodes.

Interestingly, pushing the training to 500k timesteps negatively impacted the model, as seen in as seen in Figure \ref{fig:map3_metrics},
leading to what appears to be catastrophic forgetting, which was also observed in the first map.
However, while the 500k agent in the first map successfully recovered due to its dense rewards,
the Map 3 agent's performance permanently fell to a $0\%$ success rate and a $-0.995$ average return
and with a lack of a dense reward policy was unable to re-converge
